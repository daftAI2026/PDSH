# DSH 私密模式

[English](README.en.md) · 简体中文

<!-- pdsh:description:start -->
遮挡侧栏标题、自定义昵称与头像，截取并打码编辑当前窗口。不提供会话隔离。
<!-- pdsh:description:end -->

DeepSeek Harness Desktop 插件 · **0.5.6 版本** · [`v0.5.6`](https://github.com/daftAI2026/PDSH/tree/v0.5.6)

支持 macOS 和 Windows，截图助手随插件提供，无需单独安装。

![插件设置与侧栏效果示例](https://raw.githubusercontent.com/daftAI2026/PDSH/main/docs/preview.jpg)

## 功能

- **标题遮挡**：点击帽子按钮，切换工作区和会话标题的灰条遮挡。
- **本地身份**：自定义昵称，生成或上传头像，也可使用账号头像。身份替换默认关闭。未登录时也可替换“更多”入口的显示身份，原生菜单保持可用。
- **截图编辑**：拍摄当前 DSH 窗口，点击检测到的区域或手动画框打码，调整背景和边距后复制或保存。侧栏收起时，可从会话右上角的相机进入。
- **截图私密**：“私密标题”遮挡侧栏会话标题，“私密身份”遮挡侧栏头像和昵称。两个开关独立，切换后重拍。只有重拍成功才更新图像和开关，失败时两者保持不变。身份覆盖仅用于本次编辑。
- **背景图库**：提供五张预设背景，可添加自己的图片，或获取最多五张系统壁纸。刷新系统壁纸不会清除已存图片。
- **插件更新**：在详情页检查稳定版本，确认后通过官方管理器安装，不静默安装或自行重启。

## 安装

在 Harness **插件 → 添加插件 → GitHub 仓库地址**中填写：

```text
https://github.com/daftAI2026/PDSH
```

固定版本请选择 `v0.5.6`；已安装用户可在插件详情页确认升级。

**旧版提醒**：`0.3.2` 及更早版本首次升级需正常加载一次；运行中的 `0.5.0` 不支持免重启升级。[兼容说明](PUBLISHING.md#升级兼容)。

## 环境与边界

- 目标宿主为 **DeepSeek Harness Desktop 0.2.0-rc.2**。截图支持 macOS 14+（Apple Silicon 和 Intel）与 Windows 10 1903+ x64。无需另装截图助手，也不要单独启动助手或双击 EXE。
- 选择账号头像需先登录。退出登录后暂时使用生成头像，登录后恢复原来的头像来源，不修改来源设置。
- 切到手绘时只隐藏检测区域，已有打码不会消失。画框越出原图时只保留图内部分，失焦或取消时不添加未完成的画框。
- 图片可保存为 PNG、JPEG 或 WebP，复制为 PNG。默认保存到用户主目录下的 `Downloads`，也可另选目录。重名文件自动编号，不覆盖已有文件。保存结果未知时，先检查目录，不要立即重试。
- macOS 按 Apple 本机目录的候选顺序获取最多五张代表壁纸，不按系统版本固定分组。目录格式未知或材料关联不明确时，不新增材料，保留已存图片。只有主动获取或刷新才读取系统来源或补缺下载，普通浏览可使用缓存。
  Windows 从已安装的默认与主题图片中选取最多五张，不读取用户当前壁纸或联网下载。不足五张时显示实际数量，不下载 XP、Windows 7 等历史版本素材。
- 点击“我的图片”末尾的加号导入图片。背景图片与编辑偏好保存在本地浏览器存储中，不保存截图、源视频或原文件名。空间满时拒绝导入，不会自动删除已有图片腾出空间。
- 检测区域复用侧栏识别规则，不是敏感内容检测。macOS 使用已研究的满窗布局，Windows 使用与截图绑定的原生客户区偏移。几何未知或不一致时，仍可手动画框。
  Windows 代表区域的预览与导出比例已验，完整像素对位及采集中途取消仍未验。
  macOS 当前版本的实机操作与原生 PNG 候选对位仍未验。
  暖切换的像素一致性、深色与反向主题、英文 Desktop、高 DPI、正常 Desktop 重启持久化、权限撤回和异常退出仍未验。
  本版正式包的 Desktop 安装与固定 SHA 升级仍待验证，详见[发布与验收说明](PUBLISHING.md#056-发布决定工作台终态与图库)。保存或复制前请检查图片。
- 显示遮挡不改变账号、原始文字、历史、日志或模型请求。PDSH 不提供会话隔离、凭据迁移或取证级隐私保证。
