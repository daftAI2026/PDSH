# DSH 私密模式

PDSH（Private DeepSeek Harness）是 DeepSeek Harness Desktop 的第三方插件，当前 **0.3.1 版本**提供侧栏显示调整和本机截图工作台，发布锚点为 `v0.3.1`。此补丁修正旧 Host 配置下的截图入口、目录提示和更新结果显示，用于官方升级路径验证，不代表实现了已安装包的 Host 热替换。精确安装件的 Desktop 完整验收、Windows 实机与无重启升级仍是独立检查；不要凭 tag 假定已完成。

PDSH 不创建隔离会话，不修改账号资料，也不是数据防泄露工具。标题和身份功能只改变显示，截图内容仍由用户检查和保存。

## 功能

- **标题遮挡**：点击侧栏搜索旁的帽子按钮，切换工作区和会话标题的灰条遮挡。原文仍保留在页面和无障碍树中。
- **显示身份**：在官方插件设置里选择本地昵称、离线生成的头像或本地光栅头像，也可以保留账号头像。它只替换侧栏的显示，不改账号资料。
- **截图工作台**：点击相机拍摄当前 DSH 窗口，再打开编辑器。可以重拍、手动画框遮挡、调整背景和边距，并复制或保存截图。
- **更新提示**：打开 PDSH 自身的插件详情时才检查稳定版本。发现更新后，先展开来源说明，再单独确认安装。不会后台轮询、静默安装或自行重启。

上述三个功能共用一个 `@daftai/pdsh` Bundle、一个官方插件入口和同一份 PDSH 设置，不是三个独立安装包。截图身份遮挡是截图设置中的独立选项，不会改变常驻侧栏身份。

## 截图工作台

截图来自当前 DeepSeek Harness 进程中唯一识别到的普通窗口，包含原生窗口边框。它不是仅截网页，也不是桌面全屏截图。编辑器的背景、渐变、颜色和边距属于导出内容，不代表宿主主题。截图身份遮挡默认开启，只尝试遮挡已识别的侧栏头像和名称；聊天正文、菜单及其他像素仍可能含有敏感信息。自动区域建议不猜页面坐标，用户可以手动遮挡并检查最终图片。

安装或启用插件不会启动截图或请求录屏权限。只有用户明确点击相机后，系统才会按平台处理所需权限；插件不会自动授予权限、绕过拒绝或重启 Harness。Windows 版本不主动申请管理员权限。

目标平台为 macOS 14 及以上（Apple Silicon 和 Intel），以及 Windows 10 1903 及以上 x64。Windows 原生助手由 MSVC 编译并随包分发，用户不需要双击 EXE 或单独安装它；插件会在点击相机后按需启动助手，完成后退出。Windows Desktop 实机验收留待后续，不表示已通过。其他平台和 Windows ARM64 不在此版本支持范围内。拒绝或撤销系统授权时，拍摄可能不可用，PDSH 不绕过系统边界。

### 保存与复制

保存格式为 PNG、JPEG 或 WebP，剪贴板始终复制 PNG。询问模式每次使用 Harness 官方目录选择器；直接保存模式使用已经接受的目录设置。选择的是文件夹，不是原生“另存为”文件对话框。文件名由 PDSH 根据设置模板生成，重名时自动编号，不覆盖已有文件。

默认目录是当前用户 home 下的 `Downloads`，Windows 默认形如 `C:\Users\用户名\Downloads`。这只是默认路径，不保证跟随用户对系统 Downloads Known Folder 的重定向。需要其他目录时，用官方目录选择器另选。

正常取消不会报告保存成功，也不会覆盖已有文件。若连接在提交结果返回前中断，保存结果可能未知；先检查所选目录，不要立即重试以免产生重复文件。

## 安装与升级

目标宿主是 **DeepSeek Harness Desktop 0.2.0-rc.2**。侧栏入口和标题识别针对该版本的 DOM 适配，不声明兼容其他 Harness 版本。PDSH 不修改或重签官方应用。

在 **插件 → 添加插件 → GitHub 仓库地址**中填写 `https://github.com/daftAI2026/PDSH` 安装；需要固定版本时选择 `v0.3.1`。已安装的旧版用户应通过官方插件管理器完成升级，不要手动编辑设置文件。新版 Client 收到旧 Host 的配置时会暂停截图并说明需要重启，而不是误报目录或系统授权问题。不要把候选源码或推送提交当作安装完成。安装第三方插件即运行其代码，请先审查来源与依赖。

升级提示只在 PDSH 自身详情页检查稳定 tag。新版本需要用户展开来源信息并确认安装，安装后遵从 Harness 提示的加载或重启时机。当前详情页收到需要重启的安装回执时，会弹出宿主原生提示；选择“稍后重启”只关闭弹窗，详情中的提醒仍保留。页面重载或插件重新挂载不保证保留此提示，不要把提示消失当作升级已经生效。普通功能开关无需重启。Git 推送本身不会更新已安装插件。

目标 Harness 版本替换已安装的同名插件时要求重启：先保存未完成的工作，正常退出并重新打开 DSH。安装清单显示新版本并不代表 Host 已加载新代码；仅刷新页面或再次“立即启用”不能代替这一步。首次安装的“立即启用”用于启用配置层，不是升级包的热替换接口。[官方 HMR 已知限制](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/boot/hmr/README.zh.md#known-limitations-and-deferred-work)也区分了源码热加载与已安装包版本替换。当前 DSH 未向插件开放一键重启接口，PDSH 不绕过它或显示无法兑现的“立即重启”按钮。

## 隐私边界

侧栏遮挡不改变原始文字、账号数据或模型请求。截图身份遮挡和手动画框只处理导出的图片，不清除应用历史、日志、网络请求或其他窗口中的内容。PDSH 不提供会话隔离、历史清除、凭据迁移或取证级隐私保证。保存或复制前请检查图片。

## 开发

```text
src/host/            单 Host 配置、官方 Remote 整窗/保存与原生 helper
src/shared/          Host/Client 共享验证与文案
src/client/          设置、侧栏适配、更新入口与生命周期
src/client/capture/  截图编辑、背景、遮挡、导出与 DSH 主题样式
locale/              官方离线发现的中英文包元信息
tests/               配置、DOM、样式来源、Remote 与生命周期合同
```

手写源码和测试使用 TypeScript/TSX。根目录 `index.js`、`client.js`、`client.js.map`、生成的 Typert face 和原生 helper 是随包提交的运行产物。可见 UI 规则和 DSH token 来源见 [`style-sources.json`](style-sources.json)，架构与协作边界见 [`AGENTS.md`](AGENTS.md)。

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm run bundle
pnpm release:check # 提交完成且工作树清洁后运行
```

Node/jsdom 合同测试、构建和归档检查分别回答不同问题，不能单独证明安装后的 Desktop UI 或 Windows 实机行为。
