# Desktop 手绘 E2E 规程

本规程验证已安装候选的真实手绘链路。
它不授权安装、前台切换、重启或公开发布。
先核对本次授权，再执行对应动作。

## 证据身份

每份结果绑定实际运行的候选与归档。
脏树必须记录差异摘要，不只记 HEAD。
开始前填写以下身份，不写用户内容。

| 字段 | 本次值 |
| --- | --- |
| 候选版本 | `<candidate-version>` |
| 源码 HEAD SHA | `<source-sha>` |
| 脏树摘要 | `<dirty-tree-diff-sha256-or-clean>` |
| 归档 SHA-256 | `<archive-sha256>` |
| 宿主构建 | `<exact-host-build>` |
| 系统版本 | `<os-version>` |
| 安装身份 | `<stable-or-rc-package-and-root-id>` |
| 输入方式 | `<physical-mouse-or-os-cua-or-ax-automation>` |

候选重建后，重新核对归档摘要。
运行版本、源码 SHA 和归档必须匹配。
安装身份未知时停止，不推断 ACTIVE。

## 分层边界

各层单独记录通过、失败、取消、未运行或未知。
低层通过不能替代高层验收。

| 层 | 证据范围 | 不得替代 |
| --- | --- | --- |
| 源码与合同 | 类型、模型和自动合同 | Desktop 输入或实际像素 |
| 生成产物与归档 | 当前字节、成员、模式与摘要 | Host 实际载入 |
| 隔离 Host | 官方安装、业务版本和生命周期 | Live Desktop |
| Desktop UI | 当前入口、工具和状态读回 | 原生取像或输出像素 |
| 原生取像 | 当前窗口的实际截图源 | DOM 或 Canvas 截图 |
| 像素与输出 | 预览、保存文件和剪贴板内容 | 稳定包恢复 |
| 稳定恢复 | 实际稳定身份、配置和入口 | 其他验收层 |

jsdom 和合成 PointerEvent 只证明代码合同。
纯 DOM 截图不证明原生取像或导出像素。
AX 自动点击不证明物理鼠标手势。
AX 计数不单独证明预览或保存像素。
`isTrusted` 不单独证明输入来自物理鼠标。

## 前置条件

1. 记录冻结候选、源码 SHA 和归档 SHA-256。
2. 核对精确 Desktop、操作系统和安装身份。
3. 取得本次实机测试和必要前台操作授权。
4. 选择无敏感内容的普通 DSH 窗口。
5. 使用官方相机入口执行真实原生取像。
6. 确认工作台载入当前候选和该窗口原生截图。
7. 用官方目录选择器选择自有临时目录。

临时目录须由本次任务创建并归当前用户所有。
创建后核对真实路径、owner 和符号链接。
安装包和 Host 必须与测试候选一致。
目录归属不明时停止，不保存文件。

截图只在本机内存或自有临时目录中检查。
不上传截图，不把截图写入仓库或日志。
不读取、清理或改写用户图库。
不记录截图像素、用户路径、标题或账号。

## 鼠标输入门

真实物理鼠标才证明物理鼠标路径。
确认 OS 鼠标路径后，CUA 可验证自动输入路径。
CUA 自动输入单独标记，不称为物理鼠标。
AX 动作、DOM 事件和脚本调用不计为物理手绘。
CDP 输入和测试桩不证明物理鼠标路径。
CUA 工具名称本身不证明输入来源。

CUA 若只提供原子 drag，不得声称完成中途取消门。
不得用合成事件或直接调用控制器补齐中途取消。
无法中断真实拖拽时，停止该门并请求人工协作。
未验证的取消场景必须标为未运行或未知。

## 手绘覆盖

每笔都从空白工作区位置开始真实拖动。
每笔都执行独立的按下、移动和松开。
按下、移动或松开缺失时，不计为完成一笔。

1. 选择手绘工具和纯色遮挡样式。
2. 在十个互异位置各完成一笔。
3. 复核十个独立区域均已提交并出现在预览。
4. 对模糊样式和马赛克样式重复以上步骤。
5. 另选三十个新位置进行交错手绘。
6. 按纯色、模糊、马赛克顺序循环十轮。
7. 复核总计六十个区域，每种样式各二十个。

位置必须互异，且位于有效图像区域内。
避免互相覆盖，确保每个区域可单独识别。
逐笔确认预览，不以操作次数代替提交结果。
保存坐标不得带用户屏幕坐标或截图内容。

## 编辑与输出

1. 执行一次 Undo，确认仅移除最后一笔。
2. 执行一次 Redo，确认恢复同一区域和样式。
3. 通过官方入口重新执行原生取像。
4. 确认重拍保留已有区域与撤销历史。
5. 确认新截图和已有遮挡共同进入预览。
6. 分别选择 PNG、JPEG 和 WebP 并真实保存。
   成功保存会关闭工作台；下一格式重新取像和画框。
7. 确认每个文件来自 Host 已接受目录和有效回执。
8. 在本机打开各文件并检查实际遮挡像素。
9. 使用独立的官方复制动作复制 PNG。
10. 在获准的本地临时目标中读取并检查 PNG 像素。

不得以 Blob、Canvas 桩或成功提示证明文件已落盘。
保存目录不得由 Client 任意路径参数指定。
剪贴板验证不读取或记录原剪贴板内容。
未获覆盖剪贴板授权时，剪贴板门标为未运行。
只保留脱敏结果，不归档截图像素。
剪贴板内容变化时，不读取新的未知内容。
复制后先核对自有 PNG，再执行其他 UI 观察。

## 中途取消

每种中断都使用新的手绘尝试。
先开始真实按住的拖拽，再触发中断。
逐项验证以下实际取消路径：

- 浏览器真实发出 `pointercancel`。
- Desktop 窗口真实失去焦点。
- 手绘工具或来源切换取消当前手势。
- 官方关闭动作销毁当前工作台。

每次中断后确认区域未提交。
工作台仍开时确认草稿消失且捕获已归还。
关闭后重开，确认旧草稿没有复现。
每次中断后再完成一笔，确认输入未锁死。
工具或来源切换才是本规程的模式取消门。
遮挡样式切换不替代工具或来源切换。

若中途输入无法真实触发，立即记录缺口。
不得把松开后的状态切换伪装成中途取消。
不得反复点击来掩盖不一致或未知结果。

## AX 与截图读回

操作结束后先等 UI 和 Host 操作结算。
再发起独立 AX 查询并读取当前状态。
AX 返回旧快照时，不重复执行该操作。
获准时刷新前台视图或截取本机临时画面。
随后重新独立读取 AX 和预览状态。
仍不一致时停止并标记结果未知。
截图只在本机短暂检查，不留存或上传。

独立 AX 查询不是像素证据。
局部截图不是文件保存或剪贴板回执。
文件回执也不证明预览与导出对位。
分别核对每一层，不合并为单一通过。

## 取消测试与恢复

1. 等待取像、导出、复制和保存操作全部结算。
2. 关闭工作台并保留原有稳定包配置。
3. 通过官方管理器只卸载本次 RC。
4. 通过官方管理器重新启用稳定包。
5. 回读实际稳定身份、配置和功能入口。
6. 核对稳定图库与用户设置均未被清理。
7. 保留原有稳定 accepted 配置，不为验收改写。
8. 若配置已启用取像，核对稳定包能取像和手绘。
9. 确认无活动进程后再检查临时目录归属。
10. 只删除本次任务拥有的临时目录和导出文件。

不要清理稳定或 RC 媒体仓。
若稳定配置未启用取像，记录该门未运行。
不要删除归属不明或仍在使用的临时文件。
稳定恢复未实测时，不得报告恢复完成。

## 回执

按层填写 `done` 和 `all remaining` 两项。
在 `done` 中写门名、候选身份和结果状态。
在 `all remaining` 中写失败、未运行或未知门。
只写必要的命令、退出码和脱敏状态。
日志不得包含像素、路径、标题、账号或会话内容。

流程改进只在复核后写入本规程。
候选流水、历史计数和故障原话归私人文档。
本规程不记录单次版本结果或验收结论。
